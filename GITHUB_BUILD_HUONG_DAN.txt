KPI TAMMI AUTO SHARE V1 - BUILD APK TREN GITHUB

1. Mo repo GitHub anh muon dung.
2. Upload TOAN BO noi dung trong thu muc nay vao THU MUC GOC cua repo.
   Quan trong: phai thay cac muc app/, .github/, build.gradle.kts, settings.gradle.kts ngay o root repo.
3. Commit changes vao nhanh main hoac master.
4. Mo tab Actions tren GitHub.
5. Chon workflow "Build KPI Tammi APK".
6. Neu push vua xong workflow se tu chay. Neu chua chay: Run workflow > Run workflow.
7. Khi hien dau tich xanh: mo lan chay moi nhat > muc Artifacts.
8. Tai "KPI-Tammi-AutoShare-V1-APK".
9. Giai nen artifact, cai file KPI_Tammi_AutoShare_V1-debug.apk len Android.
